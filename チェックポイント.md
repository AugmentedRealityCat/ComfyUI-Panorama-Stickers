# チェックポイント

このブランチでは、`coverage 180/360` の実装を先に閉じ、その後に panorama rendering の shared pipeline refactor を段階的に進める。

## 現在地点

- `coverage` は backend / modal / preview に入っている
- ただし rendering architecture は未統一
- `stickers` だけ fast path、`cutout` と `preview` は旧経路が残る

## 実装フェーズ

### Phase 0: coverage branch を閉じる

- [x] `coverage` を node parameter として追加
- [x] modal inspector と node widget を連携
- [x] background / preview / output に `coverage` を反映
- [x] 設計メモを `docs/adr/0014-unified-panorama-render-pipeline.md` に記録
- [ ] 現在の working tree を checkpoint commit

### Phase 1: 共有 pipeline の土台を整理

- [ ] panorama background / object / overlay の 3 pass 契約を明文化
- [ ] view builder / scene builder / texture builder の責務を集約
- [ ] `renderCutoutViewToContext2D(...)` 依存箇所を洗い出し、 shared pipeline へ寄せる準備をする

### Phase 2: cutout object pass を shared pipeline へ移す

- [ ] `cutout` pano view で frame/object が重くなる経路を shared object pass へ移す
- [ ] `stickers` 専用 fast path を generic pano layer renderer に寄せる
- [ ] `cutout` 背景 + object の render policy を `stickers` と揃える

### Phase 3: preview orchestration を shared pipeline consumer に揃える

- [ ] node preview
- [ ] standalone preview node
- [ ] read-only modal preview
- [ ] それぞれが shared pipeline の consumer になるよう整理

### Phase 4: 残件整理

- [ ] profiling / debug hook を整理
- [ ] 不要 helper / 重複 render path / 一時 adapter を削除
- [ ] 生成物 build
- [ ] 最終 cleanup と commit

## 原則

- `stickers` / `cutout` / `preview` は同じ panorama pipeline に乗せる
- `frame` / `unwrap` は別責務として無理に混ぜない
- `video` / `3D` は「背景 source」か「配置 object」かで pass を分ける
- node id / port semantics は変えない
